## Сделано в этой сессии

1. **Подтянут origin/master** (было отставание на 6 коммитов, все — правки данных тренировки ТЕРАПЕВТИЧЕСКАЯ, только `index.html`).

2. **Исправлен темп речи: значения из блока `[BEGIN EVAL PARAMETERS]` больше не попадают в поле «Темп речи».**
   Причина: в диалог параметров значения не подставлялись, но в поле «Темп речи» (`#inputRate`) писал единственный код — восстановление настроек из сохранённой тренировки (`applyTrainingUiSettingsFromSnap`, поле `snap.speechRate`), куда любое число из старого снапшота попадало как есть, без проверки. Поэтому 1500 (интервал в мс из блока параметров, визуально похож на 1.5 × 1000) оседал в поле и переживал перезагрузку страницы.
   Изменения в `index.html`:
   - `normalizeSpeechRateValue(v, fallback)` и `getSpeechRate(preferred)` — темп нормализуется в диапазон 0.1…3 (как `MainActivity.normalizeSpeechRate` в APK). Вне диапазона (1500, 1000, 0, нечисловое) → 1.5. Пользовательские значения 1.5 / 2 / 0.5 сохраняются; запятая как разделитель дробной части допускается.
   - `readTrainingUiSettings` и `applyTrainingUiSettingsFromSnap` идут через guard → битый снапшот самолечится при следующем восстановлении.
   - Все места произнесения читают `getSpeechRate()`: `speakWithAndroidTraining`, запись MP3, `SpeechSynthesisUtterance.rate` (были прямые чтения `inputRate.value`).
   - На `change` поля «Темп речи» введённое значение нормализуется.
   - Изоляция диалога параметров: в `Gl_evalParamOverrides` попадают только те ключи, которые реально показаны в диалоге (`Gl_evalParamsShownNames`).

## Открытые вопросы / ограничения

- Точная причина попадания именно 1500 в снапшот не установлена (код-путь от блока параметров к полю «Темп речи» отсутствует); принята защита на уровне нормализации + изоляции диалога. Если значение всё же появится — смотреть содержимое `localStorage` по ключу `tcjs_last_trainings_v1`.
- Озвученный MP3 зависит от поддержки захвата звука вкладки (ПК Chrome/Edge); на Android рассчитывать на кнопку «таймер-дорожка».
- Для попадания исправлений в APK нужен пересбор CI.
