# USER_INSTRUCTIONS — инструкции пользователя

Накапливаются агентом; новые добавляются в конец (см. `.cursor/rules/save-context-before-push.mdc`).

## Процесс работы

1. Общение и документация — на русском языке.
2. **Перед каждым push:** сохранять контекст сессии в `docs/AGENT_CONTEXT.md` и инструкции пользователя в `docs/USER_INSTRUCTIONS.md`, включать оба файла в коммит (правило от 2026-08-24).
3. **Перед каждым push:** поднимать номер версии на 1 и обновлять дату: комментарий в самом верху `index.html` (`<!-- TotalCalendarJS | Версия N | ГГГГ-ММ-ДД -->`), блок `tcjs-app-build` в `index.html`, файл `app-build.txt` (правило от 2026-08-24).
4. Не использовать literal `git commit` в терминале Cursor/PowerShell — только полный путь к git.exe или `git.exe commit` (см. `.cursor/rules/git-commit-terminal.mdc`).

## Функциональные требования

5. Выбор тренировок не должен зависеть от сети: страница должна работать из локального кэша/localStorage, если GitHub недоступен (проблема была на планшете Android Chrome). Сетевые запросы — только с таймаутом.
6. Экспорт тренировки в MP3: формат как у .rtm (пары текст/интервал), промежутки времени должны попадать в файл **точно, включая миллисекунды**; округление допустимо только если точность невозможна (оказалась возможна — мс сохраняются).
7. В MP3-экспорте должны быть **РЕАЛЬНЫЕ СЛОВА** тренировки, а не только сигналы; паузы между словами — точно по запрограммированным интервалам. Кнопка «без слов» — вспомогательная (2026-08-24).
8. APK пересобирается через CI автоматически; веб-версия на github.io обновляется сама после push в master.
9. Скачивать APK нужно со страницы **Releases** репозитория (файл прикреплён как ассет), а не из артефактов Actions (2026-08-26).
10. Форма выбора дополнительных параметров (`[BEGIN EVAL PARAMETERS]`) **не должна подставлять свои значения в поля основной формы**. Значения из этого блока идут только в массив тренировки (2026-09-27).
11. Поле «Темп речи» принимает только значения в диапазоне **0.1…3** (как в приложении, `MainActivity.normalizeSpeechRate`); всё остальное, в т.ч. интервалы в миллисекундах из блока параметров, отбрасывается в пользу 1.5. Проверка обязательна при восстановлении настроек из сохранённой тренировки (2026-09-27).
12. Тренировка «ЛИМФОДРЕНАЖ ЧЕРЕЗ ДВИЖЕНИЕ»: два прохода по 10 движений (5 направлений рук × согнутые/прямые), все движения лёгкие и в полуприседе; между проходами — переворот корпуса (взгляд вверх), тот же комплекс повторяется (2026-10-27).
13. В тренировке «ЛИМФОДРЕНАЖ ЧЕРЕЗ ДВИЖЕНИЕ» отдельный отдых между движениями не нужен: следующее движение начинается сразу, а время отдыха входит в общее время движения (20 с = около 10 повторений + отдых). Параметр отдыха из блока [BEGIN EVAL PARAMETERS] убран (2026-10-27).
